Before you upload

Your file is checked automatically against the official CAT Question Submission Form (form code CAT-GEN-v 1). It is accepted only if it matches the template exactly:

  • Saved as a Word .docx file (not .doc / .pdf), under 10 MB, with no tracked changes or macros.
  • A4 portrait, normal margins, footer "Form code: CAT-GEN-v 1" untouched.
  • All headings, the Instructions and the Note are unchanged; no paragraphs or tables added or removed.
  • Section A: all 10 rows filled (course code like CYB 3201, year like 2026/2027, date as DD-MM-YYYY).
  • Section B: topic, number to appear (1–5), number to attempt (≤ number to appear), compulsory Yes/No. Topic must match the Section C heading.
  • Section C: exactly 5 questions numbered 1–5, each with a stem, parts (a), (b)… each ending "(N marks)", a "Screenshots:" line, and part marks that add up to the Marks column.
