# Adelani AI Tools

- **[Handwritten Theory Grader](grader/)**: hosted version with sign-in, super-admin user management and AI reading/marking. Runs on **Cloudflare Workers** (`worker/`) or any Node.js host (`server/`). See **[DEPLOY.md](DEPLOY.md)**. The `grader/` folder alone still works as a stand-alone page.
- **[Handwritten Theory Grader, stand-alone](grader/)**: a browser-based OCR and rubric-scoring tool for handwritten theory examinations (offline Tesseract.js, optional OCR.space, examiner review, agreement statistics). See [grader/README.md](grader/README.md).
- **[AI Video/Clip Detector demo](index.html)**: a metadata-heuristic demo shell.
