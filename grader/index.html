How to use the tool

  1. Rubric. Write each question's maximum mark, model answer and keyword groups. The parsed preview shows exactly what the scorer will use.
  2. Scripts. Upload scans (JPG, PNG or PDF). Check each page is complete and legible, rotate it if needed, and either leave it on auto (answers are split on "Q1", "Question 2" … markers) or assign the page to one question.
  3. OCR & score. Pages are cleaned (handwriting boost), recognised and scored. Tesseract.js runs entirely in this browser. OCR.space is used only if you switch it on and supply a key.
  4. Review. For every question you see the scan, the recognised text (editable — scores update as you correct it), the similarity, matched and missing keywords and the suggested mark. Green, amber and red show how confident the scoring is, so start with amber and red. Accept or change each mark, then confirm the script. Scripts near the pass mark are flagged for full re-marking.
  5. Results. Export marks as CSV and save the session as JSON (a backup, or to move to another computer).
  6. Evaluation. Optional: compare the tool's unedited marks with examiners' marks (MAE, RMSE, Bland–Altman, QWK, ICC, Spearman, confusion matrix, κ, McNemar), compute OCR error rates and compare marking times.

Important limits

  • The suggested score is a first reading, not a final grade. Every mark must be reviewed by an examiner.
  • Scoring measures word overlap, not meaning. Answers in vocabulary the rubric did not anticipate can be under-scored, and lists of keywords can be over-scored. Add alternatives to the keyword groups.
  • Mathematical notation, formulae and diagrams are not recognised reliably. Use the tool for prose answers.
  • Faint, skewed, shadowed or low-resolution scans (below about 150 dpi) give much worse OCR.

Using it on a phone or tablet

  • Open the app's web address in Chrome (Android) or Safari (iPhone/iPad). On Android, choose ⋮ → Add to Home screen / Install app. On iPhone, tap Share → Add to Home Screen. It then opens like an ordinary app.
  • In Settings → OCR engine, tap Pre-load offline OCR model once while you are online (about 7 MB). After that, marking works with no connection.
  • Tap 📷 Photograph a script, then 📷 + page for more pages. Hold the phone directly above the page, in good light, with no shadow.
  • Phones get smaller working images to save memory. Each page takes about 10–30 seconds to read, depending on the phone.

Privacy and offline use

Everything (rendering, preprocessing, OCR with Tesseract.js, scoring and storage) runs in this browser. Sessions are saved in this browser's local storage. After the first visit the app works without an internet connection. Serve the folder over HTTP (e.g. GitHub Pages, or python3 -m http.server in this folder). Opening index.html directly from disk blocks the OCR web worker in most browsers.
