Import the KIU registration workbook

One Excel file with the sheets Course Units, Course Lecturers, Students and Student Course Enrolments (optionally Lecturer Logins and Student Logins with passwords). It creates lecturer accounts (username = KIU email), programmes and course units, student accounts (username = admission number) and one examination per student per course unit. Safe to run again — nothing is duplicated and no exam progress or existing password is changed.

Change students' programme

For students moving to another programme. Upload an Excel file with the sheets Students (admission number + the new programme), Student Course Enrolments (the course units of the new programme) and, optionally, a sheet of removals (its name contains Removal; rows whose Area is Student Course Enrolments and Action contains REMOVE). The KIU VP developer-handoff workbook works as it is. Course units may be given by course code, or by course_id when the same file says which code that id is.

Check file shows exactly what will change and changes nothing. Apply changes then does it. Each student is all-or-nothing: if anything for a student cannot be done, nothing is changed for that student. A course unit the student has already started is never removed.

Practice test for every student

Lets every student try the system before the real examinations, with the same 10 simple questions (Mathematics and English, multiple choice and True/False).

  1. Upload practice-questions.xlsx (or .csv) in 2. Question bank above. Its course column is PRACTICE.
  2. Click Give every student a practice sitting. Each student account gets a PRACTICE sitting next to its real course units and signs in with its usual login.
  3. Set the practice test's own time below. It is separate from the real examinations: their Settings and Timetable never change it, and it never changes them. The practice test is Section A only.
  4. Afterwards, Remove practice sittings. Real examinations are never touched.

Section A — multiple choice

Enforced on every programme and course unit (not the practice test): each candidate gets this many questions, drawn at random from their unit's bank; questions assigned by hand under Uploads → 3 are cut to the first this many. A candidate signed in but not started gets the new number when they press Start. A candidate writing now finishes the paper on screen, and when it is completed it is marked on this many — the questions they answered first. Papers already completed are marked on it straight away. Answers are never deleted: clearing the box puts every paper back.
Applies to every Section A question in every programme and course unit, whatever the marks column of the question files says. Results are worked out with it from now on, including papers already written. Blank uses each question's own marks.
The latest moment a student may begin. Anyone who starts before it still gets the full duration, so the examination ends by the last start plus the duration — students are shown all three: Opens at · Last start · Ends by.

Duration, opening time and last start here are the defaults. Course units with their own times on the Timetable tab use those instead.
